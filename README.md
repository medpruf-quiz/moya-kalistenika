# Моя калистеника

Локальное iPhone-приложение-трекер для Scriptable.

## Архитектура

- `bootstrap.js` — стабильный загрузчик Scriptable. Устанавливается один раз.
- `app.html` — интерфейс и логика приложения. Хранится локально на iPhone и может обновляться из приложения.
- `version.json` — небольшой публичный манифест версии.

## Приватность

Репозиторий содержит только код. Он **не содержит и не получает** историю тренировок, вес, талию, сон, питание, резервные копии или другие пользовательские записи.

На iPhone данные находятся в `Scriptable/Documents/MoyaKalistenika/data.json`; предыдущая резервная копия — `data.backup.json`. Код приложения хранится отдельно в `app.html`, предыдущая версия кода — `app.backup.html`.

Интернет не нужен для обычной работы. Он используется только при первой установке локального `app.html` и при ручном нажатии «Проверить обновление».

## Обновления

1. Разработчик обновляет `app.html` и повышает версию в `version.json`.
2. Пользователь открывает «Ещё» → «Проверить обновление».
3. Новая версия кода скачивается по HTTPS и сохраняется локально; предыдущий `app.html` резервируется.
4. `data.json` не заменяется обновлением кода. Если схема данных меняется, миграция выполняется внутри приложения.

GitHub Pages, Actions, backend, аналитика, база данных и аккаунты приложения не используются.
